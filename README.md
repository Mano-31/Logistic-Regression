# Logistic Regression Using Python

## About the Project
This project demonstrates Logistic Regression, a supervised machine learning algorithm used for classification problems.

## Concepts Covered
- Introduction to Logistic Regression
- Binary Classification
- Data Preprocessing
- Train-Test Split
- Model Training
- Prediction
- Model Evaluation

## Applications
- Student Pass / Fail Prediction
- UPI Transaction Fraud Prediction

## Evaluation Metrics
- Accuracy Score
- Confusion Matrix
- Precision
- Recall
- F1-Score

- Jupyter Notebook
